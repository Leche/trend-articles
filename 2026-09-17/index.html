    당근, 국내 최초 ‘광고 MCP’ 출시

    AI 대화로 광고 데이터 조회.

    SUMMARY
    • 당근이 국내 광고 플랫폼 최초로 MCP를 도입해 클로드, 챗GPT 같은 AI와 광고 계정을 연결했어요. 대화만으로 광고 현황과 성과를 확인할 수 있어요.
    • API 키 발급이나 코딩 없이 서버 주소 등록과 계정 인증만으로 이용 가능해요. 대화 맥락을 유지하며 이어서 분석을 구체화할 수 있는 점도 특징이에요.
    • 현재는 데이터 조회·분석에 한정되지만, 앞으로 광고 생성·수정까지 지원 범위를 넓힐 예정이에요. 광고 분석에 익숙하지 않은 소상공인의 진입장벽을 낮추려는 시도예요.
